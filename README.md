# TO-DO List

A simple browser-based task manager for keeping track of everyday tasks. Add tasks, mark them as complete, and remove them when they are no longer needed. Your list is saved in your browser so it remains available after you reload the page.

## Features

- Add tasks to your list
- Mark tasks as complete or incomplete
- Delete tasks
- Automatically save and restore tasks with browser `localStorage`
- Responsive layout with a custom visual style

## Run the app

No installation or build step is required:

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Type a task in the input box and select **Add**.
4. Click a task to mark it complete, or select **×** to delete it.

Tasks are stored locally in the browser you use. They are not synced between browsers or devices.

## Project files

- `index.html` — page structure and task input
- `style.css` — layout and visual styling
- `script.js` — task actions and local storage
- `icon.png`, `checked.png`, `unchecked.png` — images used by the interface
